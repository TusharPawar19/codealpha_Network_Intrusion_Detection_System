# Network Intrusion Detection System (NIDS) Prototype

A lightweight, beginner-friendly Network Intrusion Detection System built for college cybersecurity projects. It uses Suricata for packet inspection and rule-based detection, Python for alert collection, SQLite for storage, and Streamlit for a web-based visualization dashboard.

## Features
- **Suricata Integration:** Reads EVE JSON logs generated by Suricata.
- **Custom Rules:** Includes a sample `custom.rules` file for basic port scan and anomaly detection.
- **Dashboard:** Interactive Streamlit dashboard showing alert trends, top source IPs, protocols, and detailed alert logs.
- **Demo Mode:** Includes a mock data generator so you can test the system even without live network traffic or Suricata installed.

## Setup & Installation

### 1. Install Dependencies
Ensure you have Python 3.8+ installed. Open a terminal in the project root and run:
```bash
pip install -r requirements.txt
```

### 2. Environment Configuration
The `.env` file is already created for you (copied from `.env.example`). You can modify it if you change paths.
```ini
SURICATA_EVE_LOG_PATH=suricata/eve.json
DATABASE_PATH=data/nids.db
```

## Running the NIDS

### Option A: Demo Mode (No Suricata Required)
If you don't have Suricata installed or want to test the dashboard immediately:

1. **Generate Mock Alerts:**
   ```bash
   python src/mock_data.py --count 100
   ```
   *This creates a simulated `suricata/eve.json` with 100 alerts.*

2. **Collect and Store Alerts:**
   ```bash
   python src/collector.py
   ```
   *This parses the JSON and populates the SQLite database.*

3. **Start the Dashboard:**
   ```bash
   streamlit run src/dashboard.py
   ```

*(Optional)* You can also run the mock generator in a "live" mode while the collector is running in "watch" mode:
- Terminal 1: `python src/mock_data.py --live`
- Terminal 2: `python src/collector.py --watch`

### Option B: Live Mode with Suricata
If you have Suricata installed (e.g., on Linux):

1. **Configure Suricata:** Ensure Suricata is configured to write `eve.json` logs (this is usually the default in `suricata.yaml`). Include the `suricata/custom.rules` in your rule-files list.
2. **Start Suricata:**
   ```bash
   sudo suricata -c /etc/suricata/suricata.yaml -i eth0 -S suricata/custom.rules
   ```
   *(Adjust interface and paths as needed)*
3. **Start the Collector in Watch Mode:**
   ```bash
   python src/collector.py --watch
   ```
4. **Start the Dashboard:**
   ```bash
   streamlit run src/dashboard.py
   ```

## Safety and Best Practices
- **Passive Monitoring:** This project is designed for passive monitoring (IDS), not active prevention (IPS). It does not automatically block traffic.
- **Authorized Networks:** Only monitor networks you own or have explicit permission to monitor.
- **Incident Response:** Use the dashboard to investigate suspicious `src_ip` addresses before taking action manually at your firewall.
